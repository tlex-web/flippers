**1. [Rule 1 - Bug] Serve-sequence test could not detect an unconditional write**
- **Found during:** Task 2 (teeth mutation 2)
- **Issue:** The sequence case did one update per transition, so an unconditional write also produced exactly +1 per transition; only the write-on-change case went red.
- **Fix:** Each transition is followed by a steady frame (`src.step++; view.update(src)`) that must not write. Mutation 2 now reddens both cases.
- **Files modified:** src/ui/hud.test.ts
- **Committed in:** b2cfa3b

- **Found during:** Task 1 step 6

- **Fix:** Accepted (prettier --check is a gate). Leading/trailing whitespace in a block `<p>` collapses, the copy test trims, and the opening tag is still exactly `<p id="hud-hint" class="hud-hint">`.
- **Files modified:** index.html
- **Committed in:** 9bac1c6
