## Decisions Made

- One u-flag regex `/^[^\s\p{C}\p{M}]$/u`. `\p{C}` covers Cc, Cf, Cs (lone surrogates), Co and Cn. Adding `\p{M}` closes the combining-mark gap that the reviewer's `/^\P{C}$/u` left open. `\s` catches U+00A0, a Zs character outside category C.
- Task 2 is split into a test commit and a docs commit, so `git show 085b833 -- src/input/flipper-input.ts` is the comment-only diff the acceptance criterion inspects.
- IN-06 is deferred per D-03. REST_ANGLE_TOL, REST_SETTLE_UPDATES, ANGLE_SETTLE_EPS, every transition and every setFlipperMotor call are unchanged.
