Fix: install Playwright browsers (`npx playwright install chromium`) and re-run the capture. Check `?debug=1` for collider-versus-art alignment at the left and right slings and both inlane arrows.
2. **Sling top vertex now sits inside OPEN_FIELD_REGION** (spec.ts ~L301; top vertex at y = 3.85, region maxY = 4.0) — WARNING — The top vertex is now close to the bumper-cluster mid-field. Confirm visually that it does not crowd the bumpers or lane sightlines. Fix if crowded: pull the region's maxY down, or note it as accepted.
3. **keyLabel rejects combining marks (\p{M}) and whitespace** — WARNING — On layouts whose dead keys return a bare combining mark (for example some AZERTY or Intl layouts), the cap falls back to the US label and the layout-only note stays hidden. That is safe, but the cap may then show a wrong letter. Fix: accept this tradeoff or document it in the Controls copy.

### Pillar 2: Visuals (3/4)

### Pillar 3: Color (3/4)
No color changes in scope. Not re-audited beyond confirming the diff touches no palette code.

### Pillar 4: Typography (3/4)
No type changes in scope. Key caps are `<kbd>` elements written via textContent, so there is no markup injection (T-04-36).

### Pillar 5: Spacing (3/4)
- The documented clearances are ≈ 0.453 m from the sling's lower face to the raised bat, and ≈ 0.65 m from the sling's lower-left corner to the funnel wall. The comment warns that Δ 0.40 traps a ball near the hinge, so 0.35 sits close to a cliff. A 0.05 m margin is thin, though the harness tests pin it.
- The arrow stays 0.23 m above the sensor, so arrow-to-sling spacing is unchanged relative to the sling's lower-left vertex.

### Pillar 6: Experience Design (3/4)
