## Decisions Made
- Search state is reset through one `resetSearch()` helper, called from `serveBall()`, `reServe()` and the `onNudge()` tilt branch. The plan listed the three reset sites; this is the same behavior from one place.
- The fallback guards on `this.drained === NO_BALL` before it records the active id, so it never overwrites a bus drain recorded on the same step.
- The table test asserts exactly one fixed step per `step()` call, so a FixedStepLoop accumulator drift fails loudly and cannot skew step counts.

## Deviations from Plan

None. The plan was executed as written.

- No pre-existing case needed `ballSearchSteps: 0`. Every legacy game-session, e2e, determinism and soak case stayed green with the search on by default, as research measured.
- The plan names a measured tilt "at session step 391". That is the step of the 4th nudge. `tiltInPocket` reads the state after that nudge's cooldown ticks (session step 420), so the GREEN messages print `tilt 420`. The kick and drain steps (687/777, 723/814) are the same absolute session steps as the probe.
