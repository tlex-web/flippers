<objective>
Make the first element speak: a bumper kick in the live game is heard as a runtime-synthesized
ping, through the cue pipeline every later Phase-5 sound and flash reuses.

Purpose: this is the phase tracer. It proves the presentation architecture end to end on the
real table: the rules report a registered hit through one new optional hook, the 120 Hz step
path only records a scalar cue into a fixed ring, and the render frame flushes that ring into
Web Audio nodes on a context created inside the first trusted gesture. It also lands the Wave-0
infrastructure the rest of the phase depends on (the load-flake testTimeout and the fake
AudioContext) and proves assumption A5 at the composition root. The exhaustive contract cases
for the hook, the ring and the unlock rules follow in 05-07 (wave 2), split out so each plan
stays inside the per-plan context budget.

Output: ReactiveFeedback, CueQueue/CueFeedback, the Web Audio seam, AudioEngine with the bumper
voice, AudioUnlock, the fake AudioContext, the live wiring in main.ts, the testTimeout, and the
real-table pipeline test.
</objective>
