and the ball fires up the chute onto the original table. Harder holds launch harder.

meter and pullback.

<interfaces>
Hook to ADD to PhysicsWorld (D-09), mirroring the setFlipperMotor doc voice (src/physics/types.ts:122-131):
  applyImpulse(ballId: BallId, ix: number, iy: number): void   // world impulse in kg*m/s at the center of mass
Adapter (mirror setFlipperMotor's find-by-id, planck-world.ts:694-712):
  entry.body.applyLinearImpulse(Vec2(ix, iy), entry.body.getWorldCenter(), true)  // verified in planck.d.ts applyLinearImpulse(impulse, point, wake)

Units: ball mass m = BALL_DENSITY * PI * BALL_RADIUS_M^2 = 1 * PI * 0.04, about 0.126 kg, so launch speed = impulse / m.
Climb with linear damping k = BALL_LINEAR_DAMPING (0.4/s) and g = IN_PLANE_GRAVITY (about 4.61):
  h(v) = v/k - (g/k^2) * ln(1 + k*v/g).  The chute is about 4.5 m tall (PLUNGER_REST y 6.2 up to the chute top y 1.9),
  so the top needs about v > 8 m/s. Full charge targets about 12 m/s (impulse about 1.5) and min about 3.2 m/s (impulse about 0.4, a 0.9 m dribble).
  Every launch stays far under the 60 m/s soak ceiling.

Spec anchors (src/table/spec.ts, from 03-01): PLUNGER_REST (3.15, 6.2), PLUNGER_ZONE { minX 2.9, maxX 3.4, minY 5.6, maxY 6.4 };
  the chute element (kind "chute") vertices give the chute wall x (2.9) and top y (1.9).

Controller shape (Claude's discretion on exact FSM/latch details, D-07/D-08):
  export type PlungerWorld = Pick<PhysicsWorld, "applyImpulse" | "getBalls">
  export type PlungerPhase = "idle" | "charging"
  class PlungerController { constructor(world: PlungerWorld, zone = PLUNGER_ZONE);
    onPressEdge(): void; onReleaseEdge(ballId: BallId): void; onCancelEdge(): void;
    update(): void; getCharge(): number /* [0,1] */; getPhase(): PlungerPhase }
Input shape (copy FlipperInput, reduced to one control):
  class PlungerInput { handleKeyDown(e: KeyEventLike); handleKeyUp(e: KeyEventLike); handleBlur(); handleVisibilityChange(hidden);
    drainEdges(): { press: boolean; release: boolean; cancel: boolean } /* SAME object each call */; attach(); detach() }
  KeyEventLike is imported from ../input/flipper-input (reuse; never redefine).
