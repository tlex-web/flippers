## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keyboard (Enter/NumpadEnter) -> GameInput latch -> GameSession.onStart -> addBall | Untrusted, repeatable key input creates bodies |
| drain bus event -> GameSession.service -> removeBall/addBall | Rules mutate the world's body set between steps |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-11 | Denial of Service (game integrity) | A positional drain check respawning the parked ball every frame (CR-01), or a duplicate drain double-serving | medium | mitigate | Drain read only from the bus for the active id; remove-before-add; ported CR-01 cases plus the duplicate-drain case (Tasks 2-3) |
| T-04-12 | Denial of Service (usability) | The start latch swallowing browser keys or auto-repeat re-starting | low | mitigate | preventDefault on Enter/NumpadEnter only; repeat ignored; onStart only from game-over; latch tests (Task 2) |
| T-04-13 | Tampering (body leak) | Bodies accumulating if a serve skips the removal | low | mitigate | service() always removes the drained id before any add; e2e asserts exactly one ball per serve (Task 1) |
| T-04-SC | Tampering | npm/pip/cargo installs | low | accept | No packages installed; no install surface |
