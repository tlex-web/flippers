<objective>
Stand up the Walking Skeleton's headless core: scaffold the Vite + TypeScript project, define the engine-agnostic ball/flipper/event interface, and implement a Planck.js adapter behind it that drops one bullet ball under tilted-playfield gravity inside a bounded box, driven by a fixed-timestep accumulator loop. A headless smoke test proves the ball falls and stays contained.

Phase goal framed as a developer user story (this is a headless spike — the actor is the developer/CI building the game): **As a** game developer building this pinball game, **I want to** prove a single ball obeys tunnel-proof, frame-rate-independent, heavy physics behind a stable engine-agnostic interface, **so that** I can build flippers and the real table on a foundation I trust and never have to revisit.

Purpose: This plan establishes the architectural contract (D-01, D-05, carry-forward) that every later plan and every downstream phase (2-6) builds on. Physics is isolated behind an interface so the engine decision stays empirical and reversible. Get the interface right and thin.
Output: A buildable, type-checked, lint-clean project; `src/physics/types.ts` (the contract); a working Planck adapter with one ball + boundary walls; the fixed-step loop; and a passing headless smoke test.
</objective>

<contract>
This plan CREATES the interface the whole phase and project depend on. Author `src/physics/types.ts` to this shape (N-ball-ready per carry-forward — collections keyed by id, never a single hard-coded ball):
- `PhysicsWorld` interface: `step(dtSeconds): void`; `addBall(spec): BallId`; `getBalls(): readonly BallState[]`; `getFlippers(): readonly FlipperState[]`; `getBoundarySegments(): readonly Segment[]`; `drainEvents(): CollisionEvent[]`; `getContactPoints(): readonly Vec2[]`.
- `BallState`: `{ id, x, y, vx, vy, radius, angle }` in meters/SI.
- `FlipperState`: `{ id, pivotX, pivotY, angle, length, halfWidth }`.
- `CollisionEvent`: `{ type, aId, bId, point, normalImpulse }` — typed, one-way (drained, never pushed back).
- `Segment`, `Vec2`: plain value shapes.
Snapshots are read out of pre-allocated pooled arrays/objects that `step()` mutates — no per-frame allocation. Nothing outside `src/physics/planck-world.ts` may import `planck`.
</contract>
