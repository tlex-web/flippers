<objective>
Make one engine-agnostic table spec the single origin of everything the physics world
collides with and everything the debug renderer draws, and put the outline of our
original table on screen through it.

Purpose: SC#4 ("what's hit == what's drawn cannot drift") becomes structural. Planck
chains and Canvas polylines are the same vertex lists from one `resolve()`. This also
retires the latent two-copies drift in today's `buildBoundary()`, which builds a Chain
from one array and separately returns a hand-authored segment list. The Phase-1/2
proof geometry becomes plain data (`PROOF_BOX_SPEC`), so every calibrated proof keeps
running byte-identically, and the playfield (`TABLE_SPEC`) is a second spec rather
than adapter code.

Output: `src/table/spec.ts`, `src/table/resolve.ts`, a spec-driven adapter with
`getElements()`, a renderer that draws from it, and the sandbox showing the original
table outline (outer walls, right-side chute, drain funnel, two mounted flippers).
03-02 populates the field, 03-03 proves it tunnel-proof, and 03-04 makes the real table the adapter default.
</objective>

Engine fact that corrects 03-RESEARCH Pitfall 2 (verified at node_modules/planck/dist/planck.d.ts, ChainShape doc):
