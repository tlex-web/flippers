primitive proofs to their calibrated fixture so the next plan can make the real table
the default world.

has to hold on the real seams, arcs and pockets. The soak harness and five Phase-1/2

the last proof (substep), flips the adapter default to TABLE_SPEC (D-05) and narrows
FlipperController; that work was split out of this plan to keep each plan inside the
per-plan file budget.

gate, and five primitive proofs pinned to PROOF_BOX_SPEC.
