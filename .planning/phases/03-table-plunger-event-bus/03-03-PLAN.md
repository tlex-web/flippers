Build the hold-to-charge plunger stack (LNCH-01) as a 1:1 copy of the proven
FlipperInput -> FlipperController -> thin-hook template, plus the generic
`applyImpulse(ballId, ix, iy)` primitive on the physics interface (D-09 — the same
primitive Phase-4 nudge reuses). Charge accumulates on the fixed 120 Hz step; on
release it applies a proportional impulse up the chute axis; `getCharge()` exposes
the normalized level for the meter (LNCH-02 data half).

launch. Faithful to the original `TPlunger` (scalar Boost -> proportional impulse,
NOT a spring), which is also the SIMPLER model and avoids re-introducing a
fast-thin-moving-body tunneling class (D-07). The ball's existing setBullet CCD
covers the ~11 m/s up-chute launch — no new anti-tunnel work.

Output: `plunger-input.ts`, `plunger-controller.ts`, the `applyImpulse` hook +
plunger constants, and the RED->GREEN Wave-0 proofs. This plan does NOT touch
`main.ts` or `debug-draw.ts` — composition wiring + the charge meter are 03-05
(the e2e drives the stack directly, exactly like `flipper-e2e.test.ts`).
