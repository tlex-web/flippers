## Phase Goal

**As a** pinball player, **I want to** control two flippers with the keyboard that snap up instantly, fling the ball realistically, and hold a steady cradle, **so that** the moment-to-moment pinball feel is satisfying and faithful to Space Cadet.

> This is the MVP payoff slice: after this plan a real key press raises a real flipper on the rig end-to-end. It makes the "control with the keyboard" and "hold a steady cradle" clauses of the story actually true and playable.

<objective>
Wire the whole flipper stack end-to-end on the throwaway two-flipper test rig (D-10/D-11): construct the `FlipperInput` module (attach the window listeners), construct the `FlipperController(world)`, feed the drained per-side input edges into the FSM and tick it before the physics it affects advances each frame, and add a ball-feed mechanism that drops a ball onto the flippers so feel can be judged in isolation. A headless integration test proves the full path (synthetic keydown -> latch drain -> FSM -> `setFlipperMotor` -> Planck) raises the flipper sub-frame.

Purpose: this closes the FLIP-01 loop end-to-end (near-instant response; no stuck-key/auto-repeat artifacts survive the whole path) and stands up the rig where the FLIP-03 cradle and the D-09 "heavy, not floaty" feel are judged. It is the first time input, FSM, and the physical capsule flippers run together.
Output: a keyboard-playable sandbox rig with two flippers and a ball feed, plus a headless end-to-end test that guards the input -> flipper path.
</objective>
