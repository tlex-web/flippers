## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| browser window to layout code | `applyView` reads `innerWidth`, `innerHeight`, `devicePixelRatio` and the HUD's own rect on boot, resize and dpr change | viewport metrics only; no user-supplied data |

| render bake to simulation | The static bake reads resolved geometry; the fixed-step world never sees it | `el.segments`, `el.kickFace` (read-only) |
| visual language to the player | Colors carry gameplay meaning (amber kicks, cyan guides); a new color must not imply a kick | palette constants |
| test titles and docs to future maintainers | A reader trusts the root-shot titles and 06.3 D-13 to say what the gate proves | test titles, planning records |
| text edit to test semantics | A text-only edit must not move an assertion | test source |
| automated proof to shipped look | Tests prove the layout rule and bake order; only the user can judge placement and visibility | perceptual verdict |
| executor to the dependency tree | No Playwright browser build is present, which tempts an install | package manifests |
